# OpenShelter — Feature Matrix (QA)

Generated from the code on 2026-07-08 (read-only QA pass). Every row is grounded in the
actual backend (`src/main/java/ee/sheltermap/...`, `src/main/resources/db/migration/...`)
and frontend (`frontend/src/app/...`) sources.

**Roles**

- **anonymous** — no session (backend `GuestUser`, `SecurityConfig.java` permit-all routes)
- **registered-unverified** — `REGISTERED` kind with no verification claims (`domain/RegisteredUser.java`)
- **verified** — `REGISTERED` with at least one claim (EMAIL/PHONE) — the write gate (`VerificationPolicy`, `VerificationPolicyTest`)
- **admin** — `ADMIN` kind, env-provisioned via `AdminSeeder` (`ADMIN_EMAIL`/`ADMIN_PASSWORD`)

**Backend route policy** (`config/SecurityConfig.java`): public = POST `/auth/*` (register/login/refresh/logout/password-reset), GET `/api/shelters/**` (except `/mine`), GET `/api/data-source`, GET `/api/guidance/**` + GET `/api/media/**` (the crisis-guidance public reads), `/actuator/health|info`; everything else requires a valid Bearer JWT (401 if missing, 403 if forbidden — `ApiErrorHandler.java`).

**DB tables** (Flyway, `src/main/resources/db/migration/`): `users`, `verification_claims`, `pending_verifications`, `shelters`, `user_credentials`, `refresh_tokens`, `password_reset_tokens` (V1); `pending_contact_changes` (V4); `shelter_reports`, `shelter_occupancy_reports`, `report_actions` (V9); `moderation_actions` (V10); `data_imports` (V15); `shelter_history` (V18); `shelter_info_requests` (V19); `shelter_open_status` (V22); `media_assets` + `guidance_posts` (V23 — `V23__crisis_guidance.sql`; the crisis-guidance surface — `GET /api/guidance`, `GET /api/guidance/{slug}`, `GET /api/media/{filename}` public reads and the `/admin/guidance/*` + `/admin/media/*` admin endpoints — exists but has no frontend UI yet); the removed review model's `shelter_reviews`/`review_reports` tables are dropped by V21; PII: `users.email/phone` ciphertext + `users.email_hash/phone_hash` blind indexes (programmatic V13 — `migration/V13PiiEncryptionMigration.java`).

**External services**: smtp-pulse SMTP (`SMTP_HOST`/`SMTP_USERNAME`/`SMTP_PASSWORD`, `SmtpPulseSmtpSender`), Twilio SMS (`TwilioSmsSender`, env-only creds), OSM Nominatim (client-side, `gateways/geocode-gateway.ts`), Google Maps short links `maps.app.goo.gl` (server-side redirect walk, `app/LocationResolveService.java`), Päästeamet open-data CSV `opendata.smit.ee` (weekly import, `ingestion/RegistryScheduler.java`, `REGISTRY_BASE_URL`), browser Geolocation API (no server key).
